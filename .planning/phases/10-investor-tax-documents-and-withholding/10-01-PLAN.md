Stored shape. A run is an entry of ws.runs. Keys this plan adds; none is renamed or removed:
  lines: [ line ]                          one per investor paid; on every run recorded from this plan on
  linesBasis: 'recorded' | 'confirmed'     'recorded' = stored when the distribution was recorded; 'confirmed' = stored later by a person for a run saved before this plan
  linesAt: ISO date-time    linesBy: string
  cancelled: { at: ISO date-time, by: string, why: string }      absent unless cancelled
  unchanged: id, offeringId, date 'YYYY-MM-DD', type, total (integer cents), source, file, gp, gross. status is still written when a run is recorded, exactly as before, and nothing reads it any more.
  line = { investorId: string, grossCents: integer > 0, withheld: [ w ], netCents: integer >= 0 }
  w    = { kind: 'backup' | 'foreign' | 'partnership' | 'real-property' | 'fatca' | 'state', cents: integer > 0, basisCents: integer > 0, ratePct: number | null, source: 'rule' | 'entered', why: string, confirmedBy: string, confirmedAt: ISO date-time }
  Always true of stored lines: the grossCents add up to run.total; netCents = grossCents minus that line's withheld cents; one line per investor; whole cents only.

Functions, all on NS.data (assets/js/data.js):
  runPaid(run, today) → boolean            the one test: the run is not cancelled and run.date <= today (today defaults to NS.dates.today())
  runState(run, today) → 'paid' | 'scheduled' | 'cancelled'
  buildLines(ws, { offeringId, date, total }, withheld) → [ line ]       gross from NS.data.allocate (investors with a share above zero, in its order); withheld = { [investorId]: [ w ] } or nothing; throws on a withheld entry for an investor with no share, on an amount that is not a positive whole number of cents, or when a line's withheld is more than its gross
  recordRun(ws, { offeringId, date, type, total, file, gp, gross, withheld }, { by, today, id }) → run      builds the lines, stores the run in date order (newest first), returns it; throws when total is not a positive whole number or nobody holds the offering on the date
  runLines(ws, run) → { stored: boolean, basis: 'recorded' | 'confirmed' | 'recomputed', lines: [ line ] }       stored lines as they are; for a run without them the shares worked out from positions now, withheld empty, stored false
  runRows(ws, run) → [ { investor, cents, withheldCents, netCents, line } ]      runLines joined to the investor records; cents is grossCents; an investor no longer on the register is { id, title: id }
  confirmLines(ws, runId, { by, at, gross }) → run       only for a run without stored lines: stores the shares as worked out, or gross = { [investorId]: cents } when given (must add up to run.total, else it throws); linesBasis 'confirmed'
  cancelRun(ws, runId, { by, at, why }) → run            marks the run; its lines stay; a second cancel throws
  paidLines(ws, { offeringId, investorId, from, to, today }) → [ { run, line, stored } ]       every line of every paid run dated from..to inclusive, narrowed by offering and investor when given; the one source for a period's figures (the year-end forms of this phase, the journal of phase 11)

**Hand-worked example A (the numbers the checks use).** An offering with three holders on 15 June 2026: A-1001 invested $300,000, A-1002 $200,000, A-1003 $100,000 (together $600,000). A distribution of $10,000.00 (1,000,000 cents) dated 2026-06-15:
  A-1001: 1,000,000 x 300,000 / 600,000 = 500,000.00, so 500,000 cents
  A-1002: 1,000,000 x 200,000 / 600,000 = 333,333.33..., so 333,333 with 0.333 left over
  A-1003: 1,000,000 x 100,000 / 600,000 = 166,666.66..., so 166,666 with 0.667 left over

  With $800.00 withheld from A-1002 (80,000 cents): its net is 333,333 - 80,000 = 253,333; the nets are 500,000 + 253,333 + 166,667 = 920,000 and 920,000 + 80,000 = 1,000,000.
  Later A-1003's position is corrected to $200,000 (together $700,000).
