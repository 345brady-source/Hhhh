NS.files (assets/js/filesout.js; this plan creates the workbook part; plan 11-06 adds pdf to the same object):
  workbook(sheets, { title }) → Uint8Array        one worksheet per schedule object, in order; row 1 the column headings (a money heading gets ' (' + currency + ')', a pct heading ' (%)', as toCsv does); then the rows; then the total row when present; header and total rows bold
  sheetName(title, used) → a name of at most 31 characters with : \ / ? * [ ] removed, made unique against the set used by a ' (2)' style suffix inside the 31
  Cell writing: money → <v>cents / 100</v> with the number format #,##0.00;(#,##0.00) (the division is done on the integer by splitting whole units and the two-digit remainder into text, never by a floating multiply); pct → <v>fraction</v> with 0.00%; ratio and price → 0.00; int → 0; date and every text → an inline string (t="inlineStr") with & < > " escaped, xml:space="preserve"; null or '' → no cell. No formula is ever written.
  Parts: [Content_Types].xml, _rels/.rels, xl/workbook.xml, xl/_rels/workbook.xml.rels, xl/styles.xml (fonts regular and bold, the four number formats, cellStyles with Normal), xl/worksheets/sheetN.xml (with a <cols> width per column from its longest text, capped), docProps not required.
