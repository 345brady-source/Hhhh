NS.reportsPdf (assets/js/reports-pdf.js):
  PAGE = { W: 612, H: 792, M: 54 }   US Letter portrait, 0.75 inch margins, in points
  compose(model, { kit, images, logo }) → Promise<Uint8Array> with .pages
    kit (optional) = { PDFLib, fontkit, fontBytes, boldBytes }; absent → NS.esignKit.writer() and unicodeFont() (shipped first) and the bold font as above
    images = { [photoId]: { type: 'image/jpeg' | 'image/png', bytes: Uint8Array } }   a photo block whose id is missing is drawn as its caption only and counted in .missingImages
    logo = LogoArt (default: await logoFor of the model's firm)
    Pages: a cover (when cover.on): style band = a full-width band in cover.accent with the logo and the firm's name, then title, subtitle and cover.lines; plain = the same on white with a rule in the accent; photo = the cover photo across the top half, then the same lines. Every later page: a header line (logo small, firm name, title) and a footer (model.footer on the left, 'Page n of N' on the right; N known after layout). When cover.on is false the first page starts with the header and an h1 of the title and subtitle.
    Blocks: h1 18 pt bold and h2 13 pt bold in the brand primary color, kept with the block that follows (never alone at a page foot); p and ul 10 pt with word wrap, bold runs in the bold font, italic runs drawn with a 12-degree x-skew (no oblique font is shipped); tiles in a grid of up to 4 per row (label 8 pt, value 14 pt bold), never split; tables with measured column widths, numeric columns (money, pct, ratio, int) right-aligned, the heading row repeated at the top of every page the table runs onto, the total row bold over a rule, never a lone heading row at a page foot; charts as vector rectangles and lines in the accent and primary colors with their labels, shown values and ticks as text, never split; photos (JPEG or PNG bytes) scaled to the text width keeping their aspect, never split, caption under; notes 8 pt; break starts a new page.
    File properties: Title = model.meta.title; Author, Producer and Creator = model.meta.author (C-12; never the library's own Producer); Subject = model.subtitle; CreationDate and ModDate = model.when; nothing else varies, so the same model and images give the same bytes (the writer's own random-looking names come from its seeded generator).
    A character the font cannot draw (checked on every string before any page is drawn) throws Error('This report has a character the PDF font cannot show: "<char>" (U+XXXX) in "<the first 40 characters of the string>". Change the text and try again.').
  logoFor(tenant) → Promise<LogoArt>; LogoArt = { kind: 'png' | 'jpeg', bytes } | { kind: 'mark', type, letters, colors: { p, a, ink } } | { kind: 'name', text, color }
    tenant.logo.type 'image' with a PNG or JPEG data URL (NS.brand.safeImage) → its bytes; with SVG, WebP or GIF → drawn to a canvas (longest side at most 600 px) and exported as PNG, in the browser only; any failure, or no canvas (Node) → { kind: 'name', text: tenant.shortName || tenant.name, color: primary }
    any other logo type → { kind: 'mark', type, letters, colors } with the colors the console's brand uses for the mark (brand.js), as hex
  A mark is drawn from NS.brand.markBody(type, letters, { p, a, ink }, 'sans')'s output (its path, rect, circle and text elements on the 40x40 artwork, read with a small parser: path d with fill or stroke and stroke-width, rect x y width height rx, circle cx cy r, text for the monogram letters in the bold font), scaled to the header or cover size; the artwork is never copied into reports-pdf.js.
