# Phase 16 Plan 06: the return and notification-of-change reader - Summary

The portal now reads what the sponsor's bank sends back: a NACHA return or change file (addenda 99 and 98), a CSV returns report through a column map guessed from the header for the sponsor to confirm, or one return entered by hand. Each becomes a plain item with the bank's reason in words, the account's last four digits only, and anything it cannot read is refused in one sentence. It is a library only: no page loads it until 16-11, and matching to investors is 16-08's. Nothing here is called ready: the owner checks phase 16 at 16-14.

Base commit: 00c32a762b9d115b6bdfebfeb7f56b925e6866e6 (fresh worktree, HEAD was 00c32a7, no other plan's commits). Branch pushed: wip/16-06. Not merged.
