<interfaces>
assets/js/totp.js: an IIFE that sets window.CVPortal.totp in a page and module.exports under Node; it touches nothing when it loads. Every function that hashes takes hmac(keyBytes: Uint8Array, msgBytes: Uint8Array) → Promise<Uint8Array> | Uint8Array (awaited either way).
  STEP = 30, DIGITS = 6, WINDOW = 1
  base32Encode(bytes) → 'ABCD…' (RFC 4648 alphabet, no padding); base32Decode(text) → Uint8Array (case-insensitive, spaces and dashes ignored; throws Error('The key has a character that is not allowed.') otherwise)
  hotp({ key, counter, digits = 6, hmac }) → Promise<string>   RFC 4226 dynamic truncation, zero-padded
  totp({ key, time, step = 30, digits = 6, hmac }) → Promise<string>   time in milliseconds; counter = floor(time / 1000 / step)
  verify({ key, code, time, lastStep = -1, window = 1, hmac }) → Promise<number | null>   the accepted step, or null for a malformed code (not 6 digits after removing spaces), a wrong code, or a step <= lastStep; compares in constant time over the six characters
  newKey(randomBytes) → Uint8Array(20); formatKey(base32) → groups of four separated by spaces
  otpauth({ issuer, label, key }) → 'otpauth://totp/' + encodeURIComponent(issuer) + ':' + encodeURIComponent(label) + '?secret=' + base32 + '&issuer=' + encodeURIComponent(issuer) + '&algorithm=SHA1&digits=6&period=30'
  RECOVERY_ALPHABET = '23456789abcdefghjkmnpqrstuvwxyz' (no 0, 1, i, l, o); newRecoveryCodes(randomBytes) → 10 codes 'xxxxx-xxxxx'; normalRecovery(text) → the 10 characters lower-cased with spaces and dashes removed, or '' when it is not 10 characters of the alphabet
  browserHmac(keyBytes, msgBytes) → Promise<Uint8Array>: crypto.subtle HMAC SHA-1 when globalThis.crypto && crypto.subtle && crypto.subtle.importKey exist and do not throw; otherwise demoHmacSha1 (a SHA-1 and HMAC written here, commented as the preview's only fallback, never used by the server)
  usesWebCrypto() → boolean   what the last browserHmac call used
</interfaces>
