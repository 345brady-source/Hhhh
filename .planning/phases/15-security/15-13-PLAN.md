<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| any request path → the server's files | a path must never reach the store, keys or code |
| the served page → scripts it runs | an injected or outside script could read what the person sees |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-15-25 | Information disclosure | path traversal to the store, keys or server code | critical | mitigate | exact-match list fixed at start-up, assets/ only by extension, no symlinks, never rebuilt; test fixed list |
| T-15-26 | Tampering | script injection into served pages (W-07) | high | mitigate | CSP with hashed inline scripts, no unsafe-inline for scripts, outside hosts exactly as found; tests headers, outside hosts |
| T-15-27 | Spoofing | the console framed by another site (clickjacking) | medium | mitigate | frame-ancestors 'none'; test headers |
| T-15-28 | Repudiation | a stale or invalid security.txt served (W-20) | low | mitigate | 404 when invalid or expired, warnings 30 days before; test security.txt, health |
| T-15-SC | Tampering | npm/pip/cargo installs | high | accept | no package is installed |
</threat_model>
