## Tools (SCRATCH/edgar/truth/tools/, not committed)

| tool | flags |
|---|---|
| prefill_sheet.py | `--id`, `--mode train|B`, `--runs`, `--force`. Train: the reader's newest result.json fields joined with the measure's counted candidates (exact.py's GROW 3 / SHARE 0.4 rule); doubts `check` (kind clash, reader review mark, uncounted candidate, two fields on one place), `candidate only`, `field only`. B: candidates only, every place `check`, only ids of held-out-b.json. Candidates come from run.js's own cache key (computed with measure.py when missing). |
| sheet_edit.py | `list [--page]`, `del`, `add <page> x0 y0 x1 y1 kind owner [--what --label --printed --must --doubt --printed-as --snap]`, `set id key=value`, `snap id [--tol 6]`, `meta` (signing, sure, not, clear.not, may_fill), `done`, `stats`, `--why`. Every edit logged in `edits.jsonl`. |
| overlay.py | `--id`, `--page`, `--contact`, `--dpi`, `--cands` (unplaced candidates in grey), `--crop x0,y0,x1,y1`. |
| check_sheet.py | `--id`, `--batch` (TR01-TR06, or a held-out B batch), `--all` (train sheets only), `--file`, `--done-only`, `--complete` (`NOT DONE <id>`), `--part i/n`. |
| run_edits.py | `<id> <file>`: one sheet_edit command per line, one call per page. |

Sheet keys added beside BRIEF.md's format: `source: hand|bootstrap`, `page_sizes`, `page_kinds`, `mode`, `prefilled`, `done`; per place `prefill` (origin and initial values, for the cost record).

## Proofs run

- Held-out A refused by all four tools and by `--mode B` (exit 2, nothing opened).
- B mode refuses a non-B id; train mode refuses a B id. With a stand-in B list (held-out-b.json does not exist yet; plan 06 writes it), a B prefill used no reader field (`fields 0`, every place `check`), and afterwards the PDF, source file, sheet and overlay all had access time one second below modification time (sealed). The test sheet was removed.
- check_sheet rejects a sheet with an email-shaped string (`FAIL - email-shaped string present`) and accepts it once removed.
- A done sheet refuses an edit without `--why`; a done sheet changed by hand fails (`sheet changed after done without a logged reason`), and passes again when restored.
- The manifest is identical across two runs and holds no held-out id.
