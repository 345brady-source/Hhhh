## Deviations from Plan

**1. [Rule 3 - Blocking] The class-page judge (harness.js, classes.js) was outside files_modified.** The class pages
judged investor `required`, `second` and `other`, so the plan's own Task 1 verify (every class page passes) could not
pass under D-30. Only those keys changed (item 10). Result: 55/55.

**2. [Rule 1 - Bug] The agreement could not be saved once investor signatures were optional.** agreementTodo counted
"where the investor signs" as `required !== false`. Now any investor signature (not a place for somebody else)
counts. The firm's rule is unchanged. coTodo was changed the same way.

**3. [Rule 2 - Missing] The guide hid Start/Next when nothing was required.** With every investor field optional, the
guide showed only Finish, which left an investor no way to be walked through the blanks. It now offers Start/Next
while empty fields remain. The hint is one short line: "Nothing is required. Start goes to each empty field."

**4. [Rule 2] The editor no longer offers a Required box on investor fields.** It would have contradicted signing. It
shows "Optional: investors can finish signing without completing this field." instead. Firm fields keep the box.

**5. D-33 scope cut (coordinator):** Task 3's gate runs, pin and proof work and the out-63 exact totals were skipped
(see the top of this summary).
