## Deviations from Plan

**1. [Rule 3 - Blocking] The torch wheel file comes from a different host than the index**
- **Found during:** Task 2
- **Issue:** The download.pytorch.org index links the wheel to download-r2.pytorch.org, and the proxy refuses that host.
- **Fix:** I fetched the same file path from download.pytorch.org instead, which works. I checked the wheel against the index's sha256 and its metadata file against the index's metadata sha256. The wheel lists no NVIDIA dependencies.

**2. [Rule 3 - Blocking] ONNX export uses `dynamo=False`**
- **Found during:** Task 2
- **Issue:** Since torch 2.9 the default ONNX exporter has been the torch.export one, which needs the onnxscript package. onnxscript is not on the approved list, and I did not install it.
- **Fix:** smoke.py uses the TorchScript exporter (`dynamo=False`) with opset 17, as make_fcn.py does. It works in 2.14.1, and torch prints a deprecation warning. If a later torch removes this exporter, the training plans must either keep torch at 2.14.1 or put onnxscript through the package check.

**3. Pinning method beyond the plan text.** All 25 packages were installed with `--only-binary=:all: --require-hashes` from a list built from the PyPI per-version pages, so nothing outside the approved list could be installed. pip did not upgrade itself.

**4. Executed partly in the main checkout.** My worktree was removed after the checkpoint return, so this SUMMARY is committed on the orchestrator's branch as a single-file commit. No other repository file was touched.
