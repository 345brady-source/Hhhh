## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| payment provider -> POST /billing/webhook | unauthenticated internet callers; only a valid signature is trusted, and then only the provider's API |
| operator -> POST /billing/admin/refund | ADMIN_TOKEN |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-36 | Spoofing / Tampering | forged or replayed payment webhook | high | mitigate | billing.mjs: connector.mjs verify over raw bytes with the signed timestamp and 300 s tolerance; store.seen on the event id; the charge re-read from the provider before any ledger line; tests "forged", "replay", "body not trusted" |
| T-08-37 | Elevation of privilege | a sponsor or investor refunding to a card | high | mitigate | refund only behind ADMIN_TOKEN; refused for started, credit-paid or already refunded entitlements; test "admin only" |
| T-08-38 | Tampering | refund then use (a refunded package still entitling checks, or credited as well) | high | mitigate | status refunded is final: find returns it, release refuses it, a credited one loses its credit when refunded; test "a refunded entitlement" |
| T-08-SC | Tampering | npm/pip/cargo installs | high | accept | no package is installed |
</threat_model>
