createMailer({ env, store, vault, now, tls, senders, log }) → { configured, send(m), outbox(q), purge(), release(workspace) }
  m as today plus { investorId, refId, optional: boolean, commercial: boolean, attachments } (attachments present → { emailStatus: 'failed', error: 'Emails never carry attachments.' }, nothing logged as sent)
  sender: if store.list('accounts').length > 0 and m.workspace: senders.get(m.workspace) must be ready → From and envelope are its address; else status 'held' (kept sealed in the outbox with reason 'sender_not_ready'); with no accounts: a ready sender for the workspace if one exists, else MAIL_FROM as today; m.workspace '' (staff mail): MAIL_FROM
  suppression: log.suppressed(m.to) → status 'suppressed', not sent; log.optionalOff(m.workspace, m.to) and (m.optional or m.commercial) → status 'suppressed'
  returns { emailStatus: 'sent' | 'outbox' | 'held' | 'failed' | 'suppressed', error?, logId }
  release(workspace) → sends that workspace's held messages younger than OUTBOX_DAYS now that its sender is ready; returns counts
buildMessage returns the message text as today and exposes the Message-ID it wrote (e.g. buildMessage(msg) → string with a .messageId property, or a messageId passed in by the caller); smtpSend's result keeps { response } and the mailer reads the relay id from it (/\b(?:Ok|OK|queued as)\s+<?([\w.@-]+)>?/).
server/lib/maillog.mjs: createMailLog({ store, vault, env, now }) → {
  add({ workspace, kind, refId, investorId, status, messageId, relayId, to, toName, subject, text, link }) → id   (record: { id: 'mlg_…', at, workspace, kind, refId, investorId, status, messageId, relayId, events: [], box: sealed { to, toName, subject, text: redacted } })
  event({ relayId, messageId, type, permanent, at }) → the entry updated or null; bounced+permanent → mailsuppress keyed sha256(lower(address)) { reason: 'bounced', at } and, when refId is an invitation id, that invitation's emailStatus becomes 'bounced'; complained → mailprefs-independent record { workspace, emailHash, optionalOff: true }
  list(workspace, { investorId, limit }) → newest first, opened: { id, at, kind, refId, investorId, status, events, to, subject, text }
  suppressed(address) → boolean; optionalOff(workspace, address) → boolean
  purge(nowMs) → removes entries older than MAIL_LOG_DAYS (1 to 3650, default 2555) and suppression entries never; returns count }
Routes (server/index.mjs):
