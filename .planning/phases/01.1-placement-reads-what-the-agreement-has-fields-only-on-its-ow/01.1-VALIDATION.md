> Per-phase validation contract for feedback sampling during execution.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Plain Node scripts with Playwright 1.63.0 (as phases 1 to 5), plus one Python judge (poppler, pypdf, numpy, Pillow) that needs no hand-written expectations |
| **Config file** | none — helpers in `.planning/phases/01-accurate-field-placement/checks/harness.js` and `.planning/phases/04-signing-inside-onboarding/checks/lib.js`; new ones under `.planning/phases/01.1-placement-reads-what-the-agreement-has-fields-only-on-its-ow/checks/` (Wave 0 creates them) |
| **Quick run command** | `node .planning/phases/01.1-placement-reads-what-the-agreement-has-fields-only-on-its-ow/checks/reading.js` |
| **Full suite command** | `bash .planning/phases/01.1-placement-reads-what-the-agreement-has-fields-only-on-its-ow/checks/all.sh` |
| **Estimated runtime** | quick: under 5 seconds (pure data, no browser); full: several minutes (fixtures, public documents, the held-out example, preview modes, walk, look, earlier phases, linter) |

Two folders outside the repository feed the suite and are named by environment variables: `REAL_AGREEMENT_DIR` (the owner's example and its expected fields) and `PUBLIC_AGREEMENTS_DIR` (public real agreements). A check that needs one and does not find it prints "NOT RUN" and exits non-zero. "NOT RUN" is never green.

---

## Sampling Rate

- **After every task commit:** Run the quick command and the fixture group the task touches (under 30 seconds)
- **After every plan wave:** Run the full suite, first without the two outside folders, then with them
- **Before `/gsd-verify-work`:** Full suite green with both outside folders set, in the local mode and in both preview modes
- **Max feedback latency:** 30 seconds per task commit
