## Rules every plan carries

These come from the owner's rules (`CLAUDE.md`), the locked decisions and the orchestrator's notes. Each plan's planner writes them into tasks, acceptance criteria and `must_haves`, not into a preamble.

1. **No field without a printed place** (D-01, D-03). A field is created only from something read off the page. After this phase no code path holds a position, a page fraction or "the last page".
2. **The judge, not counts.** Every task that touches reading, placing, signing or stamping verifies with `judge.py` (through `H.judge`, or offline through `pageops.js --dump`, `chain.js --pages`, `judge.py`). Any automatic field off a printed place, over printed words, between brackets or overlapping another field fails, at any confidence (D-30).
3. **Held out means held out** (D-28, D-36). The owner's example is used to judge and is run last. No rule may be justified by it alone. Every reading rule a plan introduces names the convention class it implements (RESEARCH "Conventions real agreements use", "Tying a blank to its label", "Common Pitfalls"), has a generated fixture and, where one exists, a public document. No plan may tell an executor to tune a threshold until the example passes. A failure on the example is first turned into a convention class and a generated fixture.
4. **"NOT RUN" is never green.** A check that needs `REAL_AGREEMENT_DIR` or `PUBLIC_AGREEMENTS_DIR` prints `NOT RUN` and exits 3 when the folder is missing. Both folders exist here; every executor sets both.
5. **Preview modes are part of every browser check** (D-25, D-31). Every browser check of this phase starts through `H.start()` and is run three times: `PREVIEW` unset, `PREVIEW=own-origin`, `PREVIEW=no-storage`.
6. **Confidentiality** (D-36). The example PDF, its page pictures and its text never enter the repository, a plan, a summary, a commit message or a check's printed output. Places are named by page and kind. `no-leak.js` runs before every commit of this phase once plan 01.1-12 has landed.
7. **Fixed contract.** The shapes and names under "Interface contracts" are fixed. A plan may add an optional key and must record it in its summary. It may not rename or remove a key, a function, a file, a selector or an exit code.
8. **Own files only.** A plan touches the files, functions and check files "File ownership" gives it and nothing else. A defect found in a file it does not own is reported in its summary with file, function and the failing check line; the plan does not fix it.
9. **Each executor is alone in its worktree.** A plan never relies on a sibling plan of its own wave. Scratch output goes under the plan's own scratch folder, never into the repository. Servers use the plan's own ports and are stopped.
10. **Words on screen** are the exact sentences of `01.1-UI-SPEC.md` "Copywriting Contract" (D-39). No internal terms ("anchor", "widget", "operator", "template", "envelope") and no product or vendor name on screen or in a code comment (D-37).
11. **No new dependency, no text recognition** (D-38). Nothing is installed. Each plan keeps one `T-01.1-SC` row in its threat register (never two in one plan) saying so.
12. **Tracer first, and one shape.** Each plan leads with one `type="tracer"` task: the thinnest real path through everything that plan touches, with a runnable check. Tracer tasks carry `<automated>` verification only, so the executor is not stopped (the project's `workflow.human_verify_mode` is `end-of-phase`). Things only a person can judge go into `<verify><human-check>` on a later `auto` task; the one blocking checkpoint of the phase is in plan 01.1-39.
13. **Size.** Two or three tasks, no task over five files. `estimate-calibration` returns factor 1 with confidence `low` (no samples); the smart zone is 100,000 tokens of a 200,000 window. A plan whose estimate is over that says so in its return.
14. **VALIDATION.md and ROADMAP.md** are not edited by single-plan planners (they are written in parallel). Each plan lists its per-task commands in its own `<verification>`; the planner of 01.1-39, written last, fills the Per-Task Verification Map of `01.1-VALIDATION.md` from the plans on disk.

### 1. The reading, stage by stage

```
PDF page --pageops.readPage--> PageData --anchors.find--> Found (lines, places)
        --ties.tie--> anchors (places that take an answer, each with its whole label)
        --placement.read--> proposals (type, kind, name, box) --signers.assign--> role, forType, second
        --placement.field--> the stored field (fractions, anchor, placed, kind)   + one ReadRecord per document
```

`NS.placement.read(pages, ctx)` runs the pure stages for a whole document. `assets/js/esign.js` is the only caller in the app. Nothing else creates an automatic field.

### 2. PageData (returned by `NS.pageops.readPage(lib, page, n)`, one per page)

```js
{ page,                    // 1-based page number
  w, h,                    // size of the displayed page
  chars:   [{ u, x0, x1, y, h, font, bold, italic, space, hidden }],
                           // every glyph that is horizontal as displayed. u: its unicode string; x0, x1: left and right
                           // edge; y: baseline; h: font height; font: the real font name without the six-letter subset
                           // prefix; bold, italic: read from that name; space: a space glyph; hidden: text render mode 3
  rules:   [{ x0, x1, y0, y1, made, lum }],
                           // horizontal printed lines. y0, y1: top and bottom of the ink. made: 'stroke' | 'fill'
                           // (a stroked line, or a filled rectangle at most 3 pt high and at least three times as wide)
  walls:   [{ x, y0, y1, t, lum }],          // vertical printed lines; t: thickness
  rects:   [{ x0, y0, x1, y1, t, made, lum }],
                           // every other rectangle: drawn squares, frames, shading. t: stroke width, 0 when filled
  widgets: [{ x0, y0, x1, y1, type, name, tip, check, radio, readOnly, required, multi }],
                           // the PDF's own form fields. type: 'Tx' | 'Btn' | 'Sig' | 'Ch'; tip: the tooltip
  picture,                 // 0 to 1: share of the page covered by its largest picture
  skipped,                 // glyphs left out because they are not horizontal as displayed
  capped,                  // true when a cap was reached (NS.pageops.CAPS: chars 60000, rules 20000, walls 20000, rects 20000, widgets 2000)
  error }                  // '' or one plain sentence; when set, the arrays are empty
```

`lum` is the luminance of the stroke or fill colour, 0 (black) to 1 (white). `readPage` never throws for a problem of one page: it returns `error`. It does not open the PDF: the caller opens it with `isEvalSupported: false` (D-51).

### 3. Found, Place and Anchor

```js
// NS.anchors.find(pageData, shared) -> Found
{ page, w, h,
  lines:  [{ y, x0, x1, h, text, bold, italic, words: [{ s, x0, x1, y, h, bold, italic, font }] }],
                           // printed lines of visible text, top to bottom; hidden text is left out
  places: [Place],         // every printed mark that could take an answer
  left,                    // x of the left-most visible printed mark on the page; null on an empty page
  scan,                    // true when the page is a picture of a page (picture >= 0.85), with or without text over it (D-45)
  error }

// Place
{ page, kind,              // 'line' | 'box' | 'cell' | 'form'
  x0, x1, y0, y1,          // the ink. line: y0, y1 are the top and bottom of the printed stroke and y1 is what a field
                           // rests on. box: the outer edges of the printed box. cell: the empty inside of the cell.
                           // form: the form field's rectangle
  clear,                   // line: empty paper above y0 before the next printed thing, capped at 60
  made,                    // array of 'underscores' | 'rule' | 'glyph' | 'square' | 'brackets' | 'cell' | 'form'
  short,                   // a line under 36 pt
  bracketed,               // stands between square brackets in the text: the sponsor's own text (D-04)
  form }                   // null, or the widget record of PageData

// NS.anchors.shared(pages) -> { running: [{ y0, y1, x0, x1 }] }   rules that repeat at one place on three or more pages

// NS.ties.tie(found) -> { anchors: [Anchor] }.   Anchor = Place plus:
{ label,                   // the whole label, all its printed lines joined, tidied, at most 300 characters; '' only for a
                           // tick box or a form field with no words of its own
  tie,                     // 'form' | 'before' | 'caption' | 'above' | 'statement' | 'sentence' | 'continues'
                           // (rules 1 to 7 of RESEARCH "Tying a blank to its label")
  sure,                    // false when the tie was a close call (a caption-or-label tie in a stack)
  sign,                    // '$' | '%' | '' printed directly beside the blank
  sentence,                // for tie 'sentence': the words of the sentence around the blank, at most 300 characters; else ''
  stack,                   // number shared by lines stacked under each other on one left edge; null otherwise
  part }                   // index of the piece when one rule was cut at its captions; null otherwise
```

Never a Place: an underline of words, a footnote rule, a rule that runs on every page, a frame or table border, a paragraph ruled off above and below, a white rule, a blank with characters printed on it. Never an Anchor: a line with no label, caption, stack or sentence (rule 8). A `bracketed` anchor is returned (so the read record can count it out) and never becomes a field.

### 4. Proposal, and what a stored field carries

```js
// NS.placement.read(pages, ctx) -> { fields: [Proposal], read: ReadRecord }.  pages: [PageData]; ctx: { firmNames: [], fundNames: [] }
// Proposal (points):
{ type,                    // one of the six field types that exist: signature | initials | date | name | text | checkbox
  kind,                    // signature | initials | date | amount | percentage | email | phone | taxId | address | text | checkbox (D-09)
  role,                    // 'investor' | 'firm'
  page, x, y, w, h,        // the field's box
  label,                   // the complete label cut to 60 characters, one line, no control characters
  required, conf, why,     // conf: 'high' | 'medium' | 'low'; why: one sentence when conf is not 'high'
  forType,                 // 'person' | 'entity' | absent
  prefill,                 // a key of NS.placement.PREFILL | absent
  sign,                    // '$' | '%' | absent
  second,                  // true for a second signer's, a witness's or a notary's line (D-17)
  anchor }                 // { kind, x0, x1, y0, y1, made, tie }

// NS.placement.field(proposal, pageSize) -> what autoFields stores (it adds id and signerId):
{ type, page, x, y, w, h,  // x, y, w, h: fractions of the page, with no size floor of any kind
  required, label, value: '', auto: true, confidence,
  review, reviewReason,    // only when conf is not 'high'
  forType, prefill, sign,  // only when present
  kind,
  anchor,                  // { kind, x0, x1, y0, y1, made } in points: the printed place the field sits on
  placed }                 // { x, y, w, h, type, role, label, required, prefill, forType }: what the reading wrote
                           // (x, y, w, h fractions; role 'investor' | 'firm'; prefill and forType '' when absent)
```

- `NS.placement.touched(field, role)` is true when any key of `field.placed` differs from the field as it is now (numbers compared within 1e-6; `role` is the field's present signer's role). A field with `auto` and no `placed` was stored before this phase (D-44).
- A copy made in the editor drops `auto`, `placed`, `anchor`, `confidence`, `review`, `reviewReason` (D-22).
- Box rules every stage and the judge share (D-06, D-10, UI-SPEC "What the look needs from the box's place"): a field on a line has its left and right edges on the ends of the printed line and its bottom edge on the lower edge of the line's ink (within 0.75 pt); its height never reaches the printed thing above (`clear`). A tick box covers the printed box's ink, on every side at most 0.5 pt outside it and never inside it. A signature box is taller than a text box only as far as `clear` allows.

### 5. ReadRecord

Stored as `env.read` on a draft, copied to `tpl.read` by `templateFromEnv` and onto each investor's envelope by `createFromTemplate`. An agreement with no `read` was read by an earlier version.

```js
{ v: 2,                    // version of the reading
  at,                      // ISO time
  ok,                      // false when nothing could be read
  why,                     // '' | 'scan' (every page is a picture) | 'failed' (the reader failed)
  pages,                   // pages in the PDF
  pagesRead,               // pages read (not pictures, not failed)
  scans:  [n],             // pages that are pictures of pages (D-45)
  failed: [n],             // pages whose reading failed
  counts: { boxes, blanks, signatures, initials },   // found on the pages; bracketed text is not counted; never changed by editing
  investor: { found, pages: [n] },                   // an investor signature line was read, and where (D-12)
  firm:     { found, pages: [n] },                   // a countersignature or acceptance line was read, and where
  left: [x],               // per page (index page - 1): left edge of the left-most printed mark as a fraction of the page width; null when unknown
  ms,                      // time the reading took
  again }                  // null, or { at, placed, kept, removed, marked, earlier } after "read again" (D-22, D-44)
```

- `NS.placement.summary(read, who)` returns the sentences of UI-SPEC "The read summary" in order (`who`: `{ firmSigner: bool, firmByHand: bool }`). `NS.placement.pagesList([4,5,6,9])` returns `"4 to 6 and 9"`.
- `NS.placement.REASONS` holds the five new review reasons of UI-SPEC by key: `second`, `earlier`, `tick`, `choice`, `firmBlank`.

### 10. The harness (`require(CHK/harness.js)`)

```
H.ROOT  H.CHK  H.OUT (CHECK_OUT)  H.MODE ('' | 'own-origin' | 'no-storage')
H.start(opts)            -> h { mode, top, app, context, browser, base, errors, aborted, violations, stop() }
                            top: the Page. app: what a check drives: the Page when local, the portal's Frame in a preview
                            mode. Keyboard, mouse, viewport and whole-page pictures go through top.
H.signUp(h, firm)        -> a new firm in the self-serve edition with one offering; h.app shows its console
H.fixtures(groups)       -> [{ group, doc, pdf, expected }] made under H.OUT/fixtures
H.upload(h, pdf, o)      -> { envId, fields, signers, read, todo }   through NS.esign.agreementDraft
H.uploadVia(h, pdf, o)   -> the same, through the real upload dialog
H.fieldsOf(h, envId)     -> [{ id, auto, type, kind, role, page, x0, x1, top, bottom, label, required, conf, review, why,
                               forType, prefill, sign, anchor, placed }] in points
H.judge(pdf, fields, o)  -> { ok, faults: [{ code, page, field }] }   runs judge.py
H.compare(expected, fields, read) -> [fault]   a manifest against what was placed and read
H.stored(h, fileId)      -> Buffer   a file read from the portal's own store, never through a download
H.reporter()             -> { check(name, ok, info), done() }
H.notRun(what)           -> prints "NOT RUN <what>", exits 3
```

Preview modes load `diy.html` of the worktree inside a frame on a second origin, with its six stylesheets and its scripts as the page's own files, exactly as the published wrapper page links them (CONTEXT "Specific Ideas" corrects research assumption A1).

- `own-origin`: `sandbox="allow-scripts allow-forms allow-same-origin"`. `no-storage`: `sandbox="allow-scripts allow-forms"`.
- One header on the framed document: `default-src 'none'; script-src 'self' 'unsafe-inline' https://cdnjs.cloudflare.com https://cdn.jsdelivr.net/npm/ https://unpkg.com; style-src 'self' 'unsafe-inline' https://fonts.googleapis.com; font-src https://fonts.gstatic.com data:; img-src data: blob:; connect-src 'none'; worker-src 'self' blob:; frame-src 'none'; form-action 'none'; base-uri 'none'`. `connect-src 'none'` is stricter than the host (which blocks other hosts only); it makes D-26 a fact the checks enforce.
- The three script hosts are answered from the vendor folder (pinned archives, as `01-accurate-field-placement/checks/harness.js` `vendor()` does). The font stylesheet host is answered with an empty stylesheet. Font files are never answered. Every other outside request is aborted and listed in `h.aborted`; every policy violation is listed in `h.violations`.
- When storage is refused nothing may reload the page: a check that needs an investor moves inside the one page (by hash). A step that cannot be reached without a reload is a finding to report, not a reason to skip the mode.
