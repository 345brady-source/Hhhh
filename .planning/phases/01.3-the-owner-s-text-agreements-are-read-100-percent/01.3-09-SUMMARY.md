## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] The firm could not take document C's acceptance block**
- **Found during:** walk C. The first run stopped at save with "Your firm has fields to complete but nowhere to sign. Add a signature field for your firm, or remove its fields."
- **Issue:** the reader leaves the acceptance block nobody's and optional, because it names another party. The summary tells the sponsor to set it to the firm. Changing the signer in the properties panel dropped the other party but kept `required: false`. `agreementTodo` does not count an optional signature as where a signer signs, so the save was refused, and the sponsor had no hint to tick Required.
- **Convention class:** a place for somebody else that is given to a signer becomes that signer's ordinary field. A signature or initials there is where the signer signs, so it is required by default, like any such field, until the sponsor says otherwise.
- **Fix:** `NS.changes['es-fprop']` in esign.js. When the signer of a selected `isOther` signature or initials field is changed to a real signer, `required` is cleared before `setProp`, so signer and required change in one undo step. This is the only function changed. placement.js is untouched, and no function in the picture block was edited.
- **Made-up page that proves it:** the existing class page `acceptanceOtherParty` (class-pages.js, unchanged), driven by scratch `owner-set/probe-setfirm.js`:
  - at the base: FAIL (the signature set to the firm stays optional; save refused with the sentence above);
  - after the fix: PROBE: PASS (required and unmarked; one undo returns it to somebody else's and optional; redo gives it back; the agreement saves).
- **Re-run after the fix:** scorers A, B, C, all 43 class pages, the pins, the nine check files and both walks C. All of them are in the final run above.
- **Files modified:** assets/js/esign.js
- **Commit:** 9076350
