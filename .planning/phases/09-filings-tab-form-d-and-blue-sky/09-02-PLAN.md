<interfaces>
New module, modelled on assets/js/meaning.js lines 1-10 and 510-517 (an IIFE that attaches to window.CVPortal in the browser and sets module.exports under Node, needing nothing at load). No XML library: Form D is a fixed set of elements in a fixed order with no attributes and no namespace.

NS.formD API:
  LISTS                         the schema's choice lists, verbatim (entity types, relationships, exemption codes, industry groups, fund types, revenue and net asset value ranges, state codes)
  blank()                       an empty draft
  prefill(offering, facts, rec) → { draft, sources: { [field]: 'offering' | 'investors' | 'record' }, missing: [field] }; facts is NS.filings.facts(ws, offering) and rec is NS.filings.rec(ws, offeringId) of plan 09-01, passed in (this module never reads them itself)
  validate(draft, { today, submission }) → [ { item, field, level: 'error' | 'warning', layer: 'schema' | 'edgar', message } ]
  toXml(draft, { mode: 'TEST' | 'LIVE', ccc, contact }) → text; without ccc and contact it is the review copy
  fromXml(text) → draft; throws a plain-worded error on anything that is not a Form D file
  snapshot(draft) → { minimumInvestment, totalOffering, nonAccredited, commissions, findersFees, proceedsToInsiders, relatedPersons: [ 'first|middle|last' lower case ], material } (the contract plan 09-01's changeNeeded compares; material is a stable text of issuer identity and principal place of business, industry group, exemptions, duration, securities types, business combination and the identity of sales compensation recipients; never related persons' addresses or relationships, issuer size, Item 12 addresses and states, amount sold or remaining, total investors)
The draft mirrors the schema's element names in the schema's order; its shape is documented in the module's header comment for plans 09-04 and 09-05.

facts (plan 09-01): { regime: '506b' | '506c' | ..., usd, firstSale, sold, investors, nonAccredited: { count, unanswered }, total: integer | 'Indefinite' | null, minimum, byState, outsideUS }
rec (plan 09-01): { firstSale, issuer: { street1, street2, city, state, zip, phone, entityType, entityTypeOther, yearKind, yearFormed, previousNames, signerName, signerTitle }, edgar: { cik, name }, formD: [...] }
