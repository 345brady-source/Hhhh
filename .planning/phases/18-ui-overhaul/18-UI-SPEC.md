# Phase 18 — UI Design Contract: the regal look

> Visual and interaction contract for the whole portal (sponsor console in both editions, investor portal, onboarding,
> e-signature, report builder, sign-in, every dialog). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Locked inputs: 18-CONTEXT.md D-01..D-08 (not re-asked). Where this contract and a locked decision disagree, the decision wins.

**The one-line brief.** The private bank's statement, not the startup's dashboard: porcelain paper, navy ink, a serif for
what is said, a clean sans for what is done, hairline rules instead of floating cards, one sparing gilt accent, square
shoulders, quiet motion. Every word, step, rule, number and route stays exactly as it is (D-02); only how it looks and
where three things sit changes: the help entry (D-04), the Offerings/Offering intake merge (D-05), and the console's
top bar that holds them.

**Mockups for the owner's check (sample data only):** `.planning/phases/18-ui-overhaul/mockups/`
`index.html` · `console-overview.html` · `offerings.html` · `portal-home.html` · `onboarding-step.html`, with pictures at
1280x800 and 390x844 (Chromium iPhone profile; WebKit is not installed) in `mockups/shots/`. Today's look for comparison,
same sizes: scratchpad `ui-18/today/` (19 pictures: sign-up, Overview, Offerings, Offering intake, Investors, E-sign,
Reports, Portal and brand, investor Home; the scratchpad can be lost).

## Spacing Scale

The existing ten-step scale in `tokens.css` is kept by name and value (every step but one is a multiple of 4):

| Token | Value | Usage |
|-------|-------|-------|
| `--space-2xs` | 4px | icon-to-text gaps, badge padding |
| `--space-xs` | 8px | gaps between adjacent controls (touch spacing floor), compact stacks |
| `--space-sm` | 12px | table cell vertical padding, field label to input |
| `--space-md` | 16px | default gap; table cell horizontal padding; phone page gutter |
| `--space-lg` | 24px | panel padding; gap between panels |
| `--gutter` | 32px | investor container gutter; gap between page columns |
| `--space-xl` | 40px | console page padding (desktop); page head to content |
| (new) `--space-xl2` | 48px | onboarding columns gap; phone bottom room |
| `--space-2xl` | 64px | page bottom room; investor band padding |
| `--space-3xl` / `--space-4xl` | 96px / 144px | kept for existing uses only |

Exceptions: `--space-3xs` 2px is kept for focus-ring offsets and hairline nudges only (never between content);

(controls 40px tall carry a 44px hit area through `::after`, as `.cs-bell::after` does today).

## Typography

Four sizes, two weights. One serif weight (500) for titles; the sans at 400 for reading and 500 for labels and controls.

| Role | Size | Weight | Line height | Face | Used for |
|------|------|--------|-------------|------|----------|
| Label | 14px | 500 (labels, buttons, table heads, menu) / 400 (console body, table cells, hints, meta) | 1.5 | Source Sans 3 | the console's base size (dense desk tool, as today), field labels, table text, hints, captions |
| Body | 16px | 400 | 1.5 | Source Sans 3 | investor body text, every text input/select/textarea (16px keeps iOS from zooming; PHONE LAYOUT "fields" floor), the Ask control |
| Heading | 22px | 500 | 1.25 | Source Serif 4 | panel and section headings, dialog titles, offering names in cards, secondary figures |
| Display | 32px | 500 | 1.15 | Source Serif 4 | page titles (h1), headline figures (Overview figures, investor Home band) |

- Tracking: serif −0.01em at 22 and 32; sans 0. No capitals-only text, no tracked small labels (`innerText` stays the
  words as written; checks read it).
- Optical sizing: `font-optical-sizing: auto` (the serif's display cut at 32px, its text cut at 22px).
- Figures: `font-variant-numeric: tabular-nums lining-nums` on every amount, count, date and percentage in a table or
  figure row (`.num`, `.cs-figs dd`, `.kpis dd`, `.cs-nav-count`, `.cs-bell-n`). Amounts keep today's text exactly:
  same currency format, same minus sign, no parentheses, no new rounding.
- IDs, hashes and file names keep `--font-mono` (unchanged).
- Exceptions (documented, nowhere else): **12px** at 400/500 for the menu count badges, the bell count, the legal line
  in the investor footer, and the console menu's group labels (Raise, Operate, Report, Settings: gilt, 0.04em tracking,
  sentence case as today); **28px** for page titles and headline figures at 640px and under (32px wraps short titles on a
  390px screen).
- Token map for the executor (every existing use lands on a declared size): `--text-xs` → 12px, allowed only for the
  exception list above; every other current `--text-xs` use (hints, `.sub` lines, meta, captions: 110 uses today) moves
  to `--text-sm`. `--text-sm` → 14px. `--text-md` → 16px. `--text-lg` (15 uses) → 16px at 500. `--text-xl` (12) and
  `--text-section`, `--text-display-s` → 22px serif. `--text-2xl`, `--text-display` → 32px serif.
