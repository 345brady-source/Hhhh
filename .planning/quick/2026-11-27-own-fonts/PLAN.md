# Quick 2026-11-27: serve every font from the portal's own origin

<objective>
Every page of the portal today asks an outside font host for its fonts: each investor's and sponsor's IP address goes
to that host on every page load, and with no network (the sandboxed preview, the owner's frame) the fonts silently
fall back. walk12's W5 counts these requests (kb-open, ar-letter, pb-letter fail; walk12 249 pass / 3 fail on
360482a, 12-CONTEXT). Per the orchestrator's decision (12-CONTEXT "After 12-09" item 2), every font comes from the
portal's own origin: font files from pinned npm packages, committed under assets/fonts/ with their SIL Open Font
License texts, one stylesheet of @font-face rules per family.

Purpose: no visitor data leaves for an outside host; the preview and offline use show the real fonts; typed signatures
and the PDF Unicode font work with no network.
Output: assets/fonts/, the build tool, the OWN FONTS check, the pages/brand/signature/esign/policy changes, the
updated checks, a green closing gate and walk12.
</objective>
